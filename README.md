# Data Structures  
## Hospital Management System (C++)

# Project Description
This project aims to design and implement a Hospital Management System using an appropriate data structure.
The system organizes and manages patients waiting for medical services.

#Data Structure Used
- Linked List (each node represents a patient)
Each node contains:
- Patient Name (String)
- Status (Waiting / Served)
- Pointer to next node
